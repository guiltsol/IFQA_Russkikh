# Основные команды для работы с проектом:

#### `mvn clean test`

**Что делает:** Полный цикл сборки и запуска тестов.

1. Очищает проект
2. Компилирует исходный код
3. Запускает тесты
4. Генерирует Allure результаты в `target/allure-results/`

#### `mvn allure:report`

**Что делает:** Генерирует HTML отчет на основе результатов тестов.

- Читает данные из `target/allure-results/`
- Создает HTML отчет в `target/allure-report/`

#### `mvn allure:serve`

**Что делает:** Запускает локальный веб-сервер с Allure отчетом.

- Генерирует отчет (если его нет)
- Запускает веб-сервер
- Автоматически открывает браузер с отчетом
- Сервер работает до остановки (Ctrl+C в терминале)

### Пример полного рабочего процесса:

```bash
mvn clean test

mvn allure:report

mvn allure:serve
